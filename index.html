課表管理

一個課表 = 一個人的一整套設定（時段、科目、鈴聲）。 有兩個小孩就開兩個，上面的下拉選單一秒切換。

學生用「科目／老師」；上班族可以改成「目標／地點」之類的。改了只影響顯示，資料不動。

匯入時會自動判斷：整包設定就全部取代，單一課表就加進現有清單。 這裡的 JSON 和 Windows 版共用同一個格式。
